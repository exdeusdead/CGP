# CGP Development Philosophy

## Windows 98 First

CGP will be built as a complete operational platform before individual modules are perfected.

## Engines Own Business Logic

Applications do not own platform logic. They consume CGP capabilities.

## One Engine, One Responsibility

Each Engine owns a clear domain.

## One Object, One Owner

Every domain object has exactly one owner Engine.

## Historical Data Is Immutable

Historical records such as roster snapshots, deliveries, results, and penalties are never rewritten.
